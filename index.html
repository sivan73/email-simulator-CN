📤 Sender

📚 SMTP (Simple Mail Transfer Protocol)

Submission Port: 587 (TLS) or 25 (non-encrypted)

Authentication: Before sending, the client authenticates with the SMTP server using username and password (e.g., AUTH PLAIN).

Process: Client connects → Authenticates → Sends message → Server queues for delivery

💻 Client IMAP View

📚 IMAP (Internet Message Access Protocol)

Port: 993 (TLS) or 143 (non-encrypted)

Key Features: Messages remain on the server, supports folders, syncs state across devices.

Usage: Ideal for multiple devices accessing the same mailbox.
